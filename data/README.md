# Public RadLab source snapshots

`radlab/` contains unmodified public CSV responses for the fixed 18 instrument-day cases. Exact queries, acquisition dates, byte sizes, and SHA-256 hashes are in `../reports/source_manifest.json`.

The four original files were preserved from the September 22, 2026 pilot. The 14 extension files were obtained September 26, 2026. Each requests `timestamp`, `instrument_id`, and `absorbed_dose_rate` through the public RadLab API. Acquisition dates are recorded to the day; no precise retrieval time is claimed for the earlier files.

Source: https://visualization.osdr.nasa.gov/radlab/gui/data-api/

The project MIT license covers original code and documentation, not these upstream data. No private volunteer annotation files or private correspondence are included.
